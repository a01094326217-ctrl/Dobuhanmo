# 두부한모 (Dobuhanmo)

깔끔한 한국어 쇼핑몰 UI를 목표로 만든 정적 웹사이트 MVP입니다.

## 현재 구현
- 반응형 쇼핑몰 메인 페이지
- 상품 카드 / 카테고리 필터
- 신상품 / 베스트 / 리빙 필터
- 상품 검색
- 장바구니 추가 / 삭제 / 수량 합산
- 모바일 반응형 레이아웃
- 브랜드 소개 / 푸터

## 실행
`index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## 다음 단계
실제 쇼핑몰로 발전시키려면 상품 DB, 회원가입/로그인, 주문/결제 API, 관리자 페이지, 이미지 업로드, 배송 상태 관리 등을 연결하면 됩니다.
