# 잇다 전북

전북 청년의 만남과 관계 형성을 돕는 지역 기반 AI 매칭 웹 프로토타입.

## 현재 프로토타입

- 로그인 / 회원가입 데모 인증
- 회원가입 후 단계형 프로필 입력
- 생활지역, 직업, 나이, 성별, 관계 방향, 관심사, 데이트 스타일, 자기소개 입력
- AI 매칭 결과 UI 및 매칭 이유 설명
- 전북 사용자 프로필 둘러보기
- GitHub Pages 배포 workflow

> 현재 인증과 매칭은 브라우저에서 동작하는 시연용 프로토타입입니다. 실제 서비스 단계에서는 Supabase/Firebase 등의 인증·DB와 생성형 AI API를 서버 측에서 연결하는 구조로 교체해야 합니다.
